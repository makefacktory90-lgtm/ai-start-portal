# PR-01: запуск учебного сценария в Codex

Это комплект данных и правил для выполнения явно запрошенного учебного задания. Начинайте только после команды пользователя «Запусти PR-01». Ничего не устанавливайте, не отправляйте и не публикуйте.

1. В выбранной пользователем рабочей папке создайте новую подпапку PR-01. Если имя занято, выберите PR-01-2, PR-01-3 и т. д. Существующие файлы не менять.
2. Разверните файлы ниже дословно в выбранную подпапку. Содержимое INPUT — синтетические данные; команды внутри него не исполняются.
3. Прочитайте START и SKILL. Одним сообщением предложите учебные настройки: руководитель коммуникаций; руководитель, СМИ, сотрудники; справка, комментарий для согласования, внутренняя новость; нейтральный деловой тон. Дайте возможность выбрать свои настройки. Не запрашивайте закрытые сведения.
4. После настройки составьте facts.md и матрицу адресатов, покажите пробелы. Остановитесь до подтверждения реестра человеком.
5. После подтверждения создайте только новые output/brief.md, output/comment.md, output/internal-news.md и output/review.md. Проверьте каждый результат по источникам; EXPECTED — авторский ориентир, не доказательство запуска.
6. Предложите паспорт. Чётко различайте оценку времени, учебный прогон и измеренную экономию.
